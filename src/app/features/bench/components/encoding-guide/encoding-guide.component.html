Behind the brightness

Same image. More light.

A brightness transformation of the pixels you already have. No AI, no recovered highlights, no extra detail.

  1. 01 / Decode

    Start with your pixels

    The image is read as sRGB and converted to linear light, where brightness can be scaled consistently.

  2. 02 / Boost

    Choose what shines

    Increase the light across the image or target bright areas. Each extra exposure stop doubles the luminance of fully selected pixels.

    +1 stop→2× light
  3. 03 / Encode

    Package the light for HDR

    The boosted pixels are converted to BT.2020 and PQ, with HDR color metadata so compatible viewers can interpret the result.

    BT.2020PQ / ST 2084

What glows

Direct the brightness.

Threshold sets where the full boost begins in Whites and Bright modes, with a soft transition below it.

Whites
Favors near-white pixels where all three color channels are bright.
Bright
Selects bright areas by weighted sRGB brightness, including bright colors.
All
Applies the same exposure multiplier to every pixel. No threshold needed.
